# CutMasters Barbershop

Next.js App Router prototype using Tailwind CSS, shadcn/ui-style components, Lucide React, Framer Motion, and hardcoded data.

## Setup
```bash
npm i
npm run dev
```
Then open http://localhost:3000.

## Deployment
Run `npm run build` and deploy the folder to Vercel.

## Images
Remote Unsplash images are used from `images.unsplash.com`; attribution is shown in the UI/source comments.


## Local image assets
Website imagery is bundled under `public/images/` so the prototype does not depend on external image hosting for its included visuals.
